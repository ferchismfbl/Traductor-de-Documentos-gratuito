# Traductor-de-Documentos-gratuito
Traductor de documentos: programa gratuito que corre en tu computadora y traduce Word (.docx), PowerPoint (.pptx) y libros (.epub) a más de 30 idiomas, conservando el formato original. Puedes subir varios archivos a la vez, ver el porcentaje de avance y el tiempo estimado de cada uno, quitar los que ya no quieras y descargarlos.
